# Commands

## ZSH & Terminal

`reload` -> reload kardan zsh
`exec zsh` -> restart kardan shell
`ff` -> namayesh dashboard system
`dev` -> baz kardan cheatsheet

## Files & Search

`ll` -> list file ha ba joziyat
`la` -> list file ha ba hidden ha
`cat file` -> namayesh file ba bat
`fd name` -> peyda kardan file/folder
`rg text` -> search kardan dakhel file ha

## Git

`gs` -> git status
`ga file` -> add kardan file
`gaa` -> add kardan hame file ha
`gc` -> commit kardan
`gcm "msg"` -> commit ba message
`gp` -> push kardan
`gpl` -> pull kardan
`gl` -> log kotah
`glog` -> log graph
`gd` -> diff didan
`gds` -> diff staged
`lg` -> baz kardan lazygit

## Project Workflow

`c` -> entekhab project
`z project` -> raftan be project
`devtmux name` -> tmux session baraye project
